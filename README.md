# tripl# Triple-Threat SEO Optimizer

A free, browser-based tool that restructures Shopify blog HTML to maximize
Information Gain and Entity Authority — built on the Google patent family
for landing page quality.

**Live tool:** https://starblank22.github.io/triple-threat-seo/

## What it does

Paste your Shopify blog post HTML. Get back:

- H1 / H2 / H3 hierarchy enforced (1 / ≥4 / ≥3)
- @graph JSON-LD injected (BreadcrumbList + Article + FAQPage)
- FAQ block auto-wired with internal silo links
- Schema Graph diagram showing what Google's crawlers see
- Image alt text rewritten, below-fold lazy-loaded
- Comparison tables styled for crawlability
- Liquid-safe single-quote rule throughout

## Built on

- **US 8682892 B1** — Google's Information Gain patent
- **US 2025/0086246 A1** — Landing Page Optimization via ML (Google, 2025)
- **US 12536233 B1** — AI-generated content page tailored to a specific user (Google, 2026)

## How it works

One HTML file. No login. No API key. No data leaves your browser.
All processing runs locally via DOMParser.
